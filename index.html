Como instalar

Funciona em celulares com Android 5.0 ou mais novo. A instalação leva um minuto.

Baixe o APKToque em "Baixar o app" acima. O arquivo vai para a pasta Downloads.
Abra o arquivoToque no APK. Se o Android pedir, permita "Instalar apps desconhecidos" para o navegador ou gerenciador de arquivos que você usou.
Confirme e abraToque em Instalar, abra o Caixa Fácil e informe o seu nome de atendente.

Se o celular avisar sobre "app de fonte desconhecida", é normal: o app não está na loja do Google, e é distribuído por aqui.

Usar no iPhone

No iPhone o Caixa Fácil funciona como um aplicativo web instalável: sem App Store e sem baixar arquivo.

Abra no SafariAcesse este endereço no Safari. Precisa ser o Safari.
Toque em CompartilharÉ o ícone do quadrado com a seta para cima, na barra do Safari.
Adicionar à Tela de InícioConfirme o nome e abra o Caixa Fácil pelo ícone novo, sempre por ele.

📱 Abrir no iPhone

No iPhone os dados ficam guardados no navegador do aparelho. Faça uma exportação de vez em quando ou use a sincronização.

Segurança

Todas as versões são assinadas com a mesma chave, e o Android só aceita atualizações assinadas por ela. Para conferir, a impressão digital (SHA-256) do certificado é:

7d:24:c5:2c:5d:8f:87:63:10:af:07:5b:02:79:d0:16:df:4a:ee:bd:e8:17:9b:8d:3c:43:f8:0e:d4:5a:bf:ed

Baixe o app somente deste endereço ou da aba Releases do repositório.

Perguntas frequentes

Funciona sem internet?

Sim. As vendas são registradas no próprio aparelho. A internet só é necessária para sincronizar, atualizar o app e baixar fotos e dados dos outros atendentes.

Meus dados ficam onde?

No celular. Se a loja usar a sincronização, os dados vão para um repositório privado da loja, acessível só por quem tem o token de acesso.

Atualizar apaga meu histórico?

Não. A atualização instala por cima e mantém tudo. Mesmo assim, faça uma exportação de vez em quando.

Funciona no iPhone?

Sim, pela versão web instalável. Veja a seção Usar no iPhone.
